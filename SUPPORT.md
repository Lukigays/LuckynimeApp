# Support Luckynime

Luckynime adalah proyek open-source. Support sepenuhnya sukarela dan membantu pendanaan
**hosting, rilis, dan pengembangan open-source** — tidak memengaruhi akses ke fitur apa pun.

## Saweria

Rute support utama (Indonesia):

```
https://saweria.co/Luckynime
```

## What support funds

- Server hosting untuk API dan backend
- Build rilis APK dan testing
- Pengembangan dan maintenance open-source
- Domain dan infrastruktur
